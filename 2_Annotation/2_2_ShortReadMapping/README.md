### Scripts for mapping short-read RNA-seq data from Sollars et al. to BATG-1.0
#### 2_2_1_GetData.sh - downloads short read RNA-seq data from Sollars et al.
#### 2_2_2_starBuild.sh - builds indexes for mapping RNA-seq data to BATG-1.0 using star  2.7.10b
#### 2_2_3_starmap.sh - maps RNA-seq data to BATG-1.0 using star 2.7.10b
