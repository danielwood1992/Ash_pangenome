### Scripts for repeat masking BATG-1.0
### NC_2_1_1_repeatmodeler.sh - runs RepeatModeler on the BATG-1.0 assembly using RepeatModeler v2.0.1
### NC_2_1_2_repeatclassifier.sh - runs RepeatClassifier on the consensus sequences
### NC_2_1_3_repeatmasker.sh - combining the outputs of RepeatModeler with LK's previously curated set of repeats from annotating BATG-0.5, repeatmasks the BATG-1.0 assembly using RepeatMAsker v4.1.2
