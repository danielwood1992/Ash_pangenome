### Annotation of the BATG-1.0 assembly
##### 2_1_RepeatMasking - scripts for repeat masking the assembly
##### 2_2_ShortReadMapping - scripts for ontaining and mapping short-read RNA-seq data generated in Sollars et al. 2017 to the assembly
##### 2_3_LongReadMapping - scripts for processing and mapping the long-read ONT RNA seq data generated from the BATG-1.0 individual as part of this study.
