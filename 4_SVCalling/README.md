### 4_SVCalling - calling SVs from the ONT data, using read-based and de novo assembly approaches 
### Subfolders: 
#### 4_1_ReadBased - Calling SVs based on mapping reads to BATG-1.0  
#### 4_2_Assembly - De novo assembly of reads
#### 4_3_AssemblyBased- Calls SVs based on mapping assemblies to BATG-1.0
#### 4_4_QC - assessing accuracy of SVS called from BATG-1.0 ONT data compared to hap2
#### 4_5_MergeFix - merges SVs between samples; fixes some issues with the vcf for converting to pangenome
