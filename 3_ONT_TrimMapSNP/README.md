# European ash pangenome scripts
### Scripts associated with ash pangenome publication - preprint https://doi.org/10.1101/2025.07.16.665114
### Subfolders: 
3_1_ONTQC - QC/trimming of the ONT data for 50 individuals
3_2_Mapping - Mapping the trimmed ONT data to BATG-1.0
3_3_SNPs2PCA - calls SNPs from mapped ONT data, produces a PCA
